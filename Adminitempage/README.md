# Admin Product Management

A modern admin panel built with React + Vite for managing product information.

## Features

- ✅ Add, edit, delete products
- ✅ Image upload (drag & drop support)
- ✅ Product category management
- ✅ Price management
- ✅ Product description editing
- ✅ Responsive design
- ✅ Modern UI interface

## Tech Stack

- React 18
- Vite
- Lucide React (icon library)
- Pure CSS styling

## Quick Start

1. Install dependencies
```bash
npm install
```

2. Start development server
```bash
npm run dev
```

3. Open browser and visit http://localhost:8080

## Project Structure

```
src/
├── App.jsx          # Main application component
├── main.jsx         # Application entry point
└── index.css        # Global styles
```

## Usage

1. **Add Product**: Click "Add Product" button, fill in product information and upload image
2. **Edit Product**: Click "Edit" button on product card
3. **Delete Product**: Click "Delete" button on product card
4. **Image Upload**: Supports click upload or drag & drop

## Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge
